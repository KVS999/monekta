# Монетка: версия без сервера

Мини-приложение для учёта финансов внутри Telegram. Работает полностью без сервера:

- **сама страница** лежит бесплатно на GitHub Pages;
- **данные** каждого пользователя хранятся в облаке Telegram (CloudStorage) и привязаны к его аккаунту. Они видны на всех его устройствах, и больше их никто не видит, включая вас как владельца бота.

Работает всё, кроме записи трат сообщением боту в чат: для неё нужен постоянно включённый сервер. Быстрая запись фразой («кофе 350», «такси 600 вчера») есть прямо в приложении.

## Файлы

```
index.html   страница приложения
app.js       интерфейс и логика
store.js     хранение данных в облаке Telegram
parser.js    разбор фраз «кофе 350»
config.js    настройки: ссылка «Поддержать»
```

## 1. Выложите приложение на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху нажмите **+** → **New repository**.
   - Repository name: `monetka`
   - Видимость: **Public**. Бесплатный GitHub Pages работает только для публичных репозиториев. Код станет виден всем, данные пользователей — нет: они хранятся в Telegram.
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно **все файлы из этой папки**: `index.html`, `app.js`, `store.js`, `parser.js`, `config.js`, `README.md`. Внизу нажмите **Commit changes**.
5. Откройте **Settings** → слева **Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)** → **Save**.
6. Через 1–2 минуты вверху этой страницы появится адрес вида
   `https://ваш-ник.github.io/monetka/`.
   Откройте его в браузере на телефоне: должна загрузиться Монетка с надписью «Открыто в браузере…». Значит, всё работает.

## 2. Привяжите приложение к боту

Всё делается в [@BotFather](https://t.me/BotFather), код запускать не нужно.

1. Отправьте `/mybots` → выберите своего бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Отправьте адрес из шага 1.6, например `https://ваш-ник.github.io/monetka/`.
3. Отправьте название кнопки: `Монетка`.

Откройте чат с ботом. Слева от поля ввода появится кнопка «Монетка», она открывает приложение.

**Описание бота.** Сам бот теперь на сообщения не отвечает, поэтому напишите описание, которое человек видит до нажатия «Старт»: `/mybots` → бот → **Edit Bot** → **Edit Description**. Например:

> Монетка — учёт расходов и доходов. Нажмите кнопку «Монетка» внизу, чтобы открыть приложение. Записывайте траты фразой: «кофе 350», «такси 600 вчера».

**Если раньше вы запускали серверную версию** (`npm start`), больше её не запускайте. При старте она перенастраивает кнопку меню на свой адрес.

## 3. Кнопка «Поддержать» (по желанию)

Оплата звёздами Telegram требует работающего бота, поэтому в этой версии кнопка ведёт на внешнюю ссылку. Например, на вашу страницу в Tribute (принимает донаты в Telegram), Boosty или ваш канал.

1. В репозитории откройте `config.js` → значок карандаша (**Edit**).
2. Впишите ссылку: `supportUrl: 'https://...'`.
3. **Commit changes**. Через минуту на вкладке «Статистика» появится блок «Поддержать».

## Как обновлять

Замените файл в репозитории: **Add file** → **Upload files** → перетащите новую версию → **Commit changes**. Через 1–2 минуты обновление появится у всех. Данные пользователей при этом не трогаются.

Если Telegram показывает старую версию, закройте приложение и откройте его снова.

## Ограничения

- Облако Telegram хранит до 1024 записей по 4 КБ на пользователя. Монетка складывает операции по месяцам, поэтому этого хватает примерно на 100 тысяч операций, то есть на годы ведения.
- Приложение показывает операции за последние 13 месяцев. Более старые хранятся и учитываются в балансе.
- Если открыть приложение просто в браузере, а не в Telegram, записи сохранятся только в этом браузере.
- Курсы валют берутся у ЦБ РФ при каждом открытии. Если сайт недоступен, используются последние сохранённые.
